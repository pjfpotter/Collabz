What Collabz Does

You tap "Matches". Here is everything that happens before the page appears.

A matchmaker for bootcamp students

Collabz pairs software students with business students by chemistry, not by CVs. Everybody picks tags from fixed lists, the app scores every pair, and the best fits get to talk.

1
Scan a QR code and sign up

No password. A magic link arrives in your inbox.

2
Pick tags, never type

Hero story, energy, qualities, what you are seeking. The app builds your alias, like "The Calm Captain".

3
See your top 5 and one surprise

A chemistry score ranks everyone. A random "glitch match" is added on purpose.

4
Both say yes, then talk

A connection request must be approved before a private conversation opens.

The server builds the page

This is a Server Component. Nothing secret is sent to your phone, only the result. That is why Collabz can promise the browser never receives anyone's email.

The real page, in plain English

This is the actual start of src/app/matches/page.tsx. Four lines do the whole job.

CODE 
  const viewer = await requireFinishedProfile();

  const { topFive, glitch } = await getMatchesPage(viewer.id);
PLAIN ENGLISH

Find out who is looking. If nobody is signed in, or their profile is unfinished, this line sends them elsewhere and the page stops here.

Ask the matching helper for this person's five best fits and their one surprise. The page does not calculate anything itself.

Notice what is missing: no database query and no scoring maths. The page only asks and draws. We will see why in module 4.
