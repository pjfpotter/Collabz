Safe by Default

How Collabz is built so that forgetting something leaves it locked, not open.

Doors that lock themselves

A fire door is designed to shut unless something holds it open. Collabz's riskiest tool, the "sign in as any pretend student" switcher, works the same way: off unless deliberately held on.

CODE 
export function isPretendCohortEnabled(): boolean {
  const switchedOn = process.env.PRETEND_COHORT === "on";
  const isProductionDeployment = process.env.VERCEL_ENV === "production";

  return switchedOn && !isProductionDeployment;
}
PLAIN ENGLISH

One yes/no question: is the pretend cohort allowed here?

First lock: someone must have set a setting to exactly "on". Forget to set it and the answer is no.

Second lock: are we on the real, live site? Vercel tells us.

Both must be true: switched on and not production. Even a mistaken setting on production stays refused.

💡
Fail closed

Engineers call "off unless switched on" fail closed or opt-in. Whenever AI adds a flag that unlocks something risky, ask: "what happens if this variable is missing?" The answer should be "locked".

Who is using the app right now?

Every page asks getCurrentUser(). It gathers facts, then one small function decides.

CODE 
  const { sessionUser, pretendUser } = people;

  if (sessionUser) {
    const isSuspended = sessionUser.suspendedAt !== null;
    if (isAccountFinished(sessionUser) && !isSuspended) {
      return sessionUser;
    }
    return null;
  }

  return pretendUser;
PLAIN ENGLISH

Two candidates arrive: the person from a real sign-in, and the dev switcher's pretend person.

If there is a real sign-in, it wins. Always.

A real person is accepted only if they finished sign-up and are not suspended.

Otherwise nobody. The switcher is NOT used as a fallback, so a real person is never silently swapped for a pretend one.

With no real sign-in, the pretend user (if the switcher is on here) is returned.

This function takes plain objects, so each case has a one-line test. Every page in the app depends on it, which is why the team kept it small and tested.
