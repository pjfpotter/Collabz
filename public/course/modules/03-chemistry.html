The Chemistry Formula

One small function turns "two people" into a number. Learn to read it, then you can question it.

A recipe with three ingredients

Think of a cocktail recipe: one ingredient is the base, two are only a splash. The score is one big ingredient plus two small ones.

🧩

Complement × 3

One point for each thing you are seeking that the other person can offer, counted both ways. The main signal, hence ×3.

🎶

Overlap

+1 for the same Energy, +1 for the same Vibe Diagnosis. A rapport bonus.

⚡

Tension

+1 when your Hero Stories differ. A spark bonus.

ℹ️
What is NOT in the formula

Skills, interests and course never change a score. A test pins this, so no AI edit can quietly change it.

Worked example: Sam and Priya

1
Sam seeks a Builder, and Priya is one

Complement: 1

2
Priya seeks a Storyteller, and Sam is one

Complement: 2, so 2 × 3 = 6

3
Both picked the "Sea Captain" energy

Overlap: +1

4
Their Hero Stories are different

Tension: +1

Total: 6 + 1 + 1 = 8. Swap Sam and Priya and you still get 8, because the formula looks in both directions.

The real function

This is the whole of calculateScore from src/lib/matching/score.ts. Notice there is no database in it.

CODE 
export function calculateScore(a: PersonTags, b: PersonTags, pairings: Pairing[]): ScoreResult {
  const complement =
    findSatisfiedSeekingTags(a, b, pairings).length +
    findSatisfiedSeekingTags(b, a, pairings).length;

  const sharedEnergy = findSharedTagIds(a.energy, b.energy).length > 0 ? 1 : 0;
  const sharedVibe = findSharedTagIds(a.vibeDiagnosis, b.vibeDiagnosis).length > 0 ? 1 : 0;
  const overlap = sharedEnergy + sharedVibe;

  const tension = heroStoriesDiffer(a, b) ? 1 : 0;

  return {
    score: complement * COMPLEMENT_WEIGHT + overlap + tension,
    complement,
    overlap,
    tension,
  };
}
PLAIN ENGLISH

Take two people's tags and the pairing list, and hand back a score.

Count A's wishes that B can answer, then B's wishes that A can answer, and add them. That is the complement.

Did they share an Energy? That is 1 or 0. Same question for Vibe Diagnosis.

Add the two answers together. That is the overlap.

Do their Hero Stories differ? 1 or 0. That is the tension.

Give back the total (the complement is worth 3 each), and also the three parts, so "why you match" can explain itself without recalculating.

💡
Pure functions are easy to trust

A pure function can be tested with a few lines and a hand-worked example. When you ask AI for logic, ask for it "as a pure function with no database".
